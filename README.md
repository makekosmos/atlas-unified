# Atlas

Atlas — приложение Mundus для задач и личных записей. Оно подключается к Mundus Engine: настольная версия использует данные Engine на компьютере, а Android-версия пока хранит дневник локально на телефоне.

## Скачать

Последние сборки доступны на [странице релизов Atlas](https://github.com/makekosmos/atlas-unified/releases).

| Платформа | Файл | Требования |
| --- | --- | --- |
| macOS | `Atlas.dmg` | Mac с Apple Silicon |
| Windows | `Atlas-Setup.exe` | Windows x64 |
| Android | `Atlas-Android-arm64.apk` | Android 9 или новее, ARM64 |


## Установка

### macOS

1. Откройте `Atlas.dmg` и перетащите Atlas в папку «Программы».
2. Откройте Terminal и выполните:

   ```sh
   xattr -dr com.apple.quarantine /Applications/Atlas.app
   ```

3. Запустите Atlas из папки «Программы».

Эта команда нужна, потому что приложение пока не нотарифицировано Apple. Выполняйте её после копирования приложения в «Программы».

### Windows

Запустите `Atlas-Setup.exe` и следуйте шагам установщика. Windows может показать предупреждение о неизвестном издателе.

### Android

Скачайте `Atlas-Android-arm64.apk` и откройте файл на телефоне. Если Android попросит разрешить установку из этого источника, разрешите её для приложения, которым вы открыли APK.

## Что важно знать

- На компьютере Atlas использует Mundus Engine. Запустите Engine перед Atlas.
- На Android доступен дневник. Записи хранятся в данных приложения на телефоне; удаление Atlas удалит эти локальные данные.
- Синхронизация дневника Android с другими устройствами пока не подключена.
- Atlas не устанавливает обновления автоматически. Новую версию можно скачать со [страницы релизов](https://github.com/makekosmos/atlas-unified/releases) и установить поверх текущей.
